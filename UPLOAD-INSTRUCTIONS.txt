A.R.I. v112 - compleet GitHub-uploadpakket

1. Pak A.R.I.-v112-GitHub-pakket.zip uit.
2. Open de repository nachtaap/A.R.I. op GitHub.
3. Maak bij voorkeur eerst een aparte branch om deze versie te beoordelen.
4. Upload de uitgepakte bestanden naar de hoofdmap van die branch.
   index.html moet direct in de hoofdmap staan, niet in een extra submap.
   Upload dus de bestanden, niet het zipbestand zelf.
5. Bevestig de wijzigingen op die branch.

Let op: uploaden naar de branch die GitHub Pages gebruikt, kan de live-app
bijwerken. Een aparte branch laat de huidige live-versie ongemoeid zolang
je de Pages-instellingen niet verandert en de branch niet samenvoegt.

Het pakket bevat de volledige actuele app, iconen, manifest, service worker,
documentatie en optionele ontwikkelbestanden. De oude v108-archiefzip is
weggelaten. Voor GitHub Pages is geen npm-installatie of build nodig.

Nieuw in deze versie: ari-discoveries.js. Deze file moet naast index.html
staan. De bestaande ari-v108.js blijft ook nodig: die bevat de muziek-engine.

Browserchecks en resterende testbeperkingen staan in TESTING-v112.md.
De PWA gebruikt service-worker-cache ari-v112. Wanneer een eerder bezochte
app nog oud lijkt, sluit de app/tab en open hem opnieuw zodra de nieuwe
Pages-versie is gepubliceerd.
